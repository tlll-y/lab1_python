# Toolkit

Консольное приложение на Python, реализующее калькулятор арифметических выражений и конвертер единиц измерения.

## Назначение проекта

Проект предназначен для выполнения двух основных задач:

* вычисление арифметических выражений;
* перевод значений между единицами длины, массы и температуры.

Запуск приложения выполняется из командной строки:

```bash
python3 -m toolkit
```

Для просмотра доступных команд:

```bash
python3 -m toolkit --help
```

## Установка и запуск

Для работы проекта требуется Python 3.

Сначала создаётся виртуальное окружение. Оно позволяет установить зависимости проекта отдельно от остальных программ Python на компьютере:

```bash
python3 -m venv .venv
```

После создания окружение необходимо активировать:

```bash
source .venv/bin/activate
```

После активации в начале строки терминала появляется обозначение `(.venv)`.

Затем проект устанавливается в созданное окружение:

```bash
python3 -m pip install -e ".[dev]"
```

После установки можно проверить доступные команды:

```bash
python3 -m toolkit --help
```

Для завершения работы с виртуальным окружением используется команда:

```bash
deactivate
```

## Структура проекта

Основной код программы находится в каталоге `src/toolkit`.

* `main.py` — обработка команд командной строки и вывод результата.
* `__main__.py` — точка запуска приложения.
* `calculator.py` — вычисление арифметических выражений.
* `tokenizer.py` — разбор строки выражения на отдельные токены.
* `validator.py` — проверка правильности последовательности токенов.
* `converter.py` — выполнение преобразований единиц измерения.
* `constants.py` — хранение единиц измерения и коэффициентов для преобразования.
* `errors.py` — классы ошибок проекта для разных этапов обработки данных.
* `__init__.py` — обозначение каталога `toolkit` как пакета Python.

Каталог `tests` содержит автоматические тесты для основных частей программы.

## Калькулятор

Калькулятор поддерживает целые и вещественные числа, операции `+`, `-`, `*`, `/`, а также унарные знаки `+` и `-`.

При вычислении учитывается приоритет операций: сначала выполняются умножение и деление, затем сложение и вычитание.

Обработка выражения разделена на несколько этапов:

1. строка разбивается на токены;
2. полученная последовательность проверяется;
3. выполняется вычисление.

Для вычисления выражений не используются `eval`, `exec` и `ast.literal_eval`.

Пример:

```bash
python3 -m toolkit calc "2 + 3 * 4"
```

Результат:

```text
14.0
```

## Конвертер

Конвертер поддерживает следующие единицы:

* длина: `mm`, `cm`, `m`, `km`;
* масса: `g`, `kg`;
* температура: `c`, `f`, `k`.

Названия единиц не зависят от регистра.

Для длины и массы преобразование выполняется через базовую единицу соответствующей группы. Температура преобразуется через градусы Цельсия.

Преобразование между разными группами единиц не допускается. Для температур дополнительно проверяется значение ниже абсолютного нуля.

Пример:

```bash
python3 -m toolkit convert 100 --from cm --to m
```

Результат:

```text
1.0
```

## Обработка ошибок

Некорректные входные данные обрабатываются без завершения программы с необработанным исключением.

Для калькулятора предусмотрена обработка пустого выражения, недопустимых символов, неправильной последовательности операторов и деления на ноль.

Для конвертера проверяются существование единиц измерения, принадлежность единиц к одной группе, корректность числового значения и допустимость температуры.

При ошибке командной строки сообщение выводится в `stderr`, а программа завершается с кодом `2`.

## Тестирование

Автоматические тесты находятся в каталоге `tests`.

Они проверяют:

* разбор арифметических выражений;
* проверку корректности выражений;
* основные арифметические операции;
* приоритет операций;
* унарные знаки;
* деление на ноль;
* преобразование единиц длины, массы и температуры;
* работу с разным регистром единиц;
* некорректные значения и единицы измерения;
* классы ошибок проекта и обработку некорректных данных.

Запуск тестов:

```bash
python3 -m pytest
```

Проверка кода:

```bash
ruff check .
```

При отсутствии ошибок `ruff` выводит:

```text
All checks passed!
```
